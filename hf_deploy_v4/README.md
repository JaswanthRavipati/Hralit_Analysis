# HRAlit Interactive Dashboard

Interactive visualizations exploring publication, funding, and collaboration patterns in the Human Reference Atlas literature database.

**Data:** HRAlit Database (Kong & Börner, 2024)

## Visualizations

1. **Grant-Linkage Sankey** — Funding flow from funders → organs → outputs
2. **Publication Trends** — Historical publication counts with 5-year forecast  
3. **Institution–Funder Heatmap** — Co-linked publications by country
4. **Global Collaboration Map** — International co-publication network
